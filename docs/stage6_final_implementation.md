# Stage 6 – Final Implementation and Presentation

## 6.1 Final System

The final project is a Linux-based C++ virtual biometric monitoring application.

It provides:
- Virtual biometric data generation
- Heart rate processing
- SpO2 processing
- Temperature processing
- Step tracking
- Normal/abnormal validation
- File logging
- Linux process creation
- Parent/child process identification
- Makefile-based compilation
- Linux Device Driver source component
- Git/GitHub version control

## 6.2 Final Testing Result

The C++ application was compiled and executed successfully in the Linux/WSL2 environment.

The application generated biometric readings, classified readings, displayed process information, and created a log file.

## 6.3 Achievements

The project demonstrates:
- C++
- Linux
- Linux system programming
- Process management
- File handling
- Linux Device Driver concepts
- Software architecture
- Make
- Git and GitHub

## 6.4 Limitations

- Sensor data is simulated.
- No physical biometric sensors are connected.
- The device driver is not directly integrated with the C++ application.
- Kernel-module compilation/loading was not demonstrated in the current WSL2 environment because matching kernel build headers were unavailable.

## 6.5 Future Scope

Future improvements may include:
- Real biometric sensor integration.
- Physical embedded hardware.
- User-space/kernel-space communication.
- Real-time data acquisition.
- Additional Linux system-programming features.

## 6.7 Final Outcome

The project provides a functional Linux-based software simulation of a wearable fitness tracker and demonstrates concepts from C++, Linux System Programming, Linux Device Drivers, software architecture, build systems, and version control.
